# alayparikh.github.io

Source for my interactive portfolio: **https://alayparikh.github.io**

Plain HTML, CSS, and JavaScript with a Three.js 3D scene, scroll-driven effects, and liquid-glass styling. No build step; GitHub Pages serves the `main` branch root.

- `index.html`: content (experience, projects, stack, contact)
- `styles.css`: glass material, layout, 3D reveal animations
- `script.js`: Three.js scene, scroll effects, card tilt

Profile and featured work: [github.com/alayparikh](https://github.com/alayparikh)
